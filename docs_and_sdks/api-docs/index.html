การยืนยันตัวตน (Authentication)

API ทุกบริการของ xNearby ใช้ระบบ API Key ในการยืนยันตัวตนและจัดการสิทธิ์การเข้าถึง คุณต้องแนบ API Key ทุกครั้งผ่าน Header X-API-Key (หรือ Authorization: Bearer YOUR_API_KEY) ในการส่ง Request:

HTTP Header 
X-API-Key: nb_live_your_api_key_here

รหัสสถานะ HTTP ทั่วไป (Global Status Codes)

ตารางด้านล่างคือรหัสตอบกลับมาตรฐานในระดับ Gateway ของทุก API สำหรับรหัสข้อผิดพลาดเฉพาะเจาะจงของแต่ละบริการ กรุณาดูในหน้าคู่มือของบริการนั้นๆ

HTTP Status Status Code ความหมาย / สาเหตุ
200 OK SUCCESS คำขอสำเร็จและระบบประมวลผลข้อมูลถูกต้อง
400 Bad Request MISSING_PARAMS ส่งข้อมูลพารามิเตอร์ที่จำเป็นมาไม่ครบถ้วน หรือรูปแบบไฟล์ไม่ถูกต้อง
401 Unauthorized INVALID_API_KEY ไม่มี API Key หรือ API Key ไม่ถูกต้อง / ถูกระงับการใช้งาน
402 Payment Required INSUFFICIENT_BALANCE ยอดเงินคงเหลือในบัญชีไม่เพียงพอสำหรับการเรียกใช้ API นี้ (เติมเงินได้ที่ nearbyshop.xyz)
403 Forbidden INSUFFICIENT_PERMISSIONS API Key ของคุณไม่มีสิทธิ์เข้าถึงบริการนี้ หรือ IP ของคุณติด Blacklist
404 Not Found ENDPOINT_NOT_FOUND ไม่พบ Endpoint หรือ Resource ที่ร้องขอ
429 Too Many Requests RATE_LIMIT_EXCEEDED ยิงคำขอถี่เกินขีดจำกัดที่ระบบกำหนดไว้
500 Server Error INTERNAL_ERROR เกิดข้อผิดพลาดภายในระบบเซิร์ฟเวอร์
➔ ดู Error Codes เฉพาะของ Slip Verification | ➔ ดู Error Codes เฉพาะของ TrueMoney Wallet
